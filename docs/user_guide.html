2. 快速上手指南

2.1 新增第一筆記帳

  1. 開啟應用程式，點擊主畫面右下角的 「＋」浮動按鈕 (FAB)。
  2. 在彈出的新增視窗中：
    • 輸入交易 金額。
    • 選擇 交易類型（支出 / 收入）。
    • 點選對應的 消費類別（例如：餐飲、交通、購物、娛樂等）。
    • 選擇使用的 支付方式（如：現金、信用卡、LINE Pay）。
    • 填寫可選的 備註（如：午餐便當）。
  3. 點擊 「儲存記帳」，紀錄即刻更新至首頁與統計圖表中。

2.2 編輯與刪除紀錄

  • 編輯紀錄：在交易列表中點擊任意一筆項目，即可進入編輯頁面修改內容並儲存。
  • 刪除紀錄：在交易項目上點擊垃圾桶圖示，即可確認刪除該筆帳務。

3. 進階功能教學

3.1 視圖篩選與分類統計

  • 分類過濾：點擊首頁頂部的分類標籤，即可快速篩選單一類別（如「僅顯示餐飲」）的歷史紀錄。
  • 日期範圍搜尋：支援按日、週、月切換時間區間，精準比對不同時期的財務狀況。

3.2 每週趨勢與圖表分析

  • 切換至 「分析 (Analytics)」 頁籤。
  • 透過高對比視覺長條圖檢視近七日的開銷起伏，快速發現高額消費日。
  • 檢視分類圓餅圖，了解主要開銷佔比，協助擬定合理的每月預算目標。

3.3 支付方式與自訂分類管理

  • 前往 「設定 (Settings)」 -> 「類別與支付方式」。
  • 您可根據個人習慣新增專屬分類（如：寵物、訂閱服務），並為其設定圖示與代表顏色。

4. 資料備份與安全匯出

4.1 匯出 CSV 報表

  1. 進入 「設定」 頁面，找到 「資料管理」 區塊。
  2. 點擊 「匯出 CSV 財務報表」。
  3. 選擇儲存位置，即可產生格式規範的 .csv 檔案，方便使用 Excel 或 Google 試算表做二次統計與歸檔。

4.2 JSON 資料庫完整備份與還原

  • 完整備份：點擊 「建立 JSON 資料庫備份」，系統將打包您所有的交易、分類與個人設定。
  • 資料還原：換手機或重裝 App 時，點擊 「還原 JSON 備份」 並選取舊有備份檔，即可秒級復原所有帳務。

5. Google Play 線上自動更新

本應用程式已整合 Google Play 官方 In-App Update API：

  • 前往 「設定」 -> 「檢查軟體更新」。
  • 系統將自動連線 Google Play 商店檢查是否有最新修復或新功能發布。
  • 發現新版本時，點擊 「從 Google Play 下載更新」 即可於應用程式內流暢完成下載與更新安裝！

6. 常見問題與支援 (FAQ)

Q: 記帳資料會上傳到雲端伺服器嗎？

A: 不會。所有記帳數據均儲存於您手機的本地 Room 資料庫中，極大化保護您的個人財務隱私。

Q: 如何更換手機時轉移資料？

A: 請在舊手機上點擊「匯出 JSON 備份檔」並傳送至新手機，於新手機安裝「簡單愛記帳」後選擇「還原 JSON 備份」即可。
